# Standby

Аналог iOS StandBy для Android (проверялось под Galaxy S25+, One UI 9).
Работает как системная заставка (`DreamService`): Android сам запускает её на зарядке.

## Что умеет (v0.1)
- Экран 1: огромные часы + дата
- Экран 2: часы, погода (Худжанд, Open-Meteo, без ключа), батарея
- Ночной режим 22:00–07:00 — тусклый красный
- Сдвиг пикселей раз в минуту (защита AMOLED от выгорания)
- Свайп — следующий экран, долгий тап — выход

## Сборка
- **GitHub:** каждый push в `main` → Actions → `Build APK` → артефакт `standby-debug-apk`.
- **Android Studio:** File → Open → папка проекта. Студия сама подтянет Gradle 8.11.1.

## Установка на телефон
1. Скачай APK из артефакта, установи (разреши установку из неизвестных источников).
2. Открой Standby → «Настройки заставки» → выбери «Standby — часы и виджеты».
3. «Когда запускать» → «Во время зарядки».
4. Включи автоповорот, поставь телефон горизонтально на зарядку.
